# ProPresenter Slide Builder

## Export Format

### PPTX

- 16:9 slides, equivalent to 1920x1080.
- Transparent background requested; no background image or added background shape.
- Main title appears on every slide unless a slide has a custom title.
- Title text is white, 80 pt, centered at the top.
- English text is white, 44 pt, on the left.
- Spanish text is white, 44 pt, on the right.

### PDF

- Main title appears once at the top.
- Slide labels appear in red: `Slide 1`, `Slide 2`, etc.
- Custom slide titles appear under the slide label when provided.
- English text appears under each slide label/title.
- All user-provided PDF text is black.
- Spanish text is not included.
